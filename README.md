# Simulador de Máquina de Turing 

## 📘 Descripción del Proyecto

El Simulador de Máquina de Turing es una aplicación web interactiva desarrollada en JavaScript puro que permite visualizar el funcionamiento de una Máquina de Turing paso a paso.  

Incluye un conjunto de cinco expresiones regulares predefinidas, y permite modificar o agregar nuevas sin necesidad de librerías externas.

El diseño visual está inspirado en la estética Matrix, con una interfaz negra y texto verde neón para una experiencia inmersiva y didáctica.

---

## Estructura del Proyecto

```
Simulador-Maquina-Turing
 ┣  index.html
 ┣  style.css
 ┣  MaquinaTuring.js
 ┣  Problemas.js
 ┣  UI.js
 ┗  main.js
```

Cada módulo tiene una responsabilidad clara:
- MaquinaTuring.js → Lógica de la máquina (transiciones, estados y cinta).  
  *Problemas.js → Conjunto de expresiones regulares predefinidas.  
- UI.js → Renderizado y control visual de la interfaz.  
- main.js → Punto de entrada, inicializa eventos y ejecución.
